📊 Financial Analysis Dashboard (Task 2)

This project was developed as Task 2 during my internship at SkillInfytech IT Solutions Private Limited.

The objective of this dashboard is to analyze financial performance across regions, countries, stores, and products.

🚀 Project Overview

The dashboard provides insights into:

💰 Total Revenue & Average Revenue KPIs

🌍 Region-wise Revenue Analysis

🌎 Country-wise Performance Comparison

🏬 Store-wise Revenue Breakdown

📦 Product-wise Revenue Ranking

📈 Quarterly Revenue Trend Analysis

👨‍💼 Sales Representative Performance

🛠 Tools & Technologies Used

Microsoft Power BI

DAX (Calculated Measures & KPIs)

Data Modeling

KPI Cards

Interactive Slicers (Year, Quarter, Rank)

📌 Key Insights

Asia region generated the highest revenue.

Q1 recorded the strongest quarterly performance.

Top-ranked stores contributed the majority of total revenue.

Revenue trends showed seasonal variations.
