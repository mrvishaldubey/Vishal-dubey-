COVID-19 Analytics Dashboard (2020–2022)

This project was developed as Task 1 during my internship at SkillInfytech IT Solutions Private Limited.

The objective of this project was to analyze COVID-19 trends, demographic impact, and healthcare costs using Power BI.

🚀 Project Overview

The dashboard provides insights into:

📈 Time-Series Analysis of COVID-19 Cases

🌍 Country-wise Comparison of Cases and Deaths

👥 Age Group & Gender Impact Analysis

💰 Healthcare Cost Analysis (Doctor Fee, Test Cost, Treatment Cost)

📊 Recovery Rate & Fatality Rate Calculation

📅 7-Day Rolling Average Trend Analysis

📌 Patient Satisfaction & Feedback Overview

🛠 Tools & Technologies Used

Microsoft Power BI

DAX (Calculated Columns & Measures)

Data Modeling

KPI Cards

Interactive Visualizations

Slicers & Filters

📌 Key Insights

2021 recorded the highest surge in COVID-19 cases.

Senior citizens were among the most vulnerable groups.

Healthcare costs varied significantly across countries.

Recovery rate improved over time.
